# Estudo Java + Claude Code

App de estudo com timer de ciclos, agenda do dia, exercícios, progresso, quiz e linha do tempo das 24 semanas.

**Usar no navegador ou no celular:** https://koulthy.github.io/estudo-app/
No Android, use "Instalar app" no menu do Chrome. No iPhone, use "Adicionar à Tela de Início" no Safari.

**Baixar para Windows, Mac ou Linux:** https://github.com/koulthy/estudo-app/releases

O app funciona sem internet e não coleta nenhum dado: o progresso fica salvo só no seu aparelho.

Aviso importante: Este app é só um organizador de estudos. Ele não inclui aulas, vídeos nem material de nenhum curso. Parte do plano usa cursos de plataformas pagas, como a Alura, e para fazer essas aulas é preciso ter acesso próprio a elas. Os nomes de cursos e plataformas aparecem apenas como referência, e este projeto não tem ligação oficial com nenhuma delas.
